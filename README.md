# Qt 视频下载器

## 第一个版本

“直链下载器”，基于 Qt5 的 HTTP 视频下载工具，支持断点续传、暂停/继续/取消。

```
MP4直链
    ↓
✅ 可以

普通文件
    ↓
✅ 可以

带 Range 的服务器
    ↓
✅ 可以断点续传
```





### 下载流程

```
用户输入 URL + 保存路径
        │
        ▼
   点击"开始下载"
        │
        ▼
  ┌─────────────┐
  │  校验输入    │  URL 格式、HTTP/HTTPS 协议
  └──────┬──────┘
         │
         ▼
  ┌─────────────┐
  │ 创建保存目录 │  目录不存在时自动创建
  └──────┬──────┘
         │
         ▼
  ┌─────────────┐
  │ 打开 .part   │  已有则续传，没有则新建
  └──────┬──────┘
         │
         ▼
  ┌─────────────┐
  │ 发送 HTTP 请求│  附带 Range 头（续传时）
  └──────┬──────┘
         │
         ▼
   数据写入 .part
   每 500ms 更新速度
         │
         ▼
  ┌─────────────┐
  │  下载完成？   │──否──► 暂停/取消/错误处理
  └──────┬──────┘
         │是
         ▼
  .part 重命名为正式文件
```

### 关键机制

#### 断点续传

- 下载文件保存为 `<filename>.part`
- 暂停/取消时保留 `.part` 文件
- 再次下载同一文件时，读取 `.part` 大小，发送 `Range: bytes=<已下载大小>-` 请求头
- 服务器返回 `206 Partial Content`，从断点处继续下载
- 若服务器返回 `200`（不支持 Range），自动删除 `.part` 从头重新下载

#### 状态管理

| 操作 | 按钮变化 | 文件行为 |
|------|---------|---------|
| 开始下载 | 开始→禁用，暂停/取消→启用 | 创建 `.part` |
| 暂停 | 暂停→继续 | 保留 `.part` |
| 继续 | 继续→暂停 | 读取 `.part` 续传 |
| 取消 | 全部重置 | 保留 `.part` |
| 完成 | 全部重置 | `.part` → 正式文件 |

#### 速度计算

每 500ms 采样一次：
```
speed = (当前已下载 - 上次已下载) × 1000 / 经过毫秒数
```
